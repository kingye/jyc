Why Rust

One static binary, no runtime

Zero runtime dependencies, memory safety without a GC, and predictable low-latency behaviour for a process that stays up for weeks. Deploy by copying a file.

Extending

Two traits per channel

A new channel needs only InboundAdapter and OutboundAdapter. Routing, threading, queueing, sessions and commands are inherited for free.

03

Runtime Model

Bounded concurrency, per-thread isolation, live observability.

Concurrency

Semaphore-bounded workers

The thread manager holds a tokio semaphore (default 3 permits). A new thread spawns a task, acquires a permit, and drains its own bounded mpsc queue (default 10) one message at a time. Empty queue releases the permit and the task exits.

Messages within a thread are strictly serial — different threads run in parallel. Live injection lets a new message reach an in-flight agent turn.

Per-message worker

Deterministic turn pipeline

1
store + attachmentsappend to the daily chat history, save allow-listed files
2
commandsparse, execute and strip in a single pass
3
dispatchstatic text, OpenCode service, or the in-process agent
4
replyagent tool call, or fallback text via the outbound adapter
Observability

Thread event bus & TUI

Each thread owns an isolated event bus; agent activity is converted into thread events and streamed to the inspect server. The dashboard renders live threads, processing state, cost, git branch and changed files, with an embedded chat pane.

Deployment

systemd or Docker

Both modes support automatic restart and AI self-bootstrapping — the agent can rebuild and redeploy JYC from source, then come back up on the new binary.

04

Configuration Layers

User-edited config stays separate from generated state, following platform conventions.

Three levels

Global → workdir → thread

L1
config dirshared config.toml, skills/, templates/
L2
workdir / data rootown config.toml plus all generated state per channel and thread
L3
threadrestricted model overrides, sessions, chat history, published files

L2 is deep-merged over L1: tables merge recursively, arrays and scalars are replaced. Skills are scanned at every level with higher levels winning; templates resolve L3 to L2 to L1, first match wins.

Platform paths

XDG on Unix, AppData on Windows

PlatformConfigData
Linux / macOS~/.config/jyc~/.local/share/jyc
Windows%APPDATA%\jyc%LOCALAPPDATA%\jyc

Secrets use environment-variable interpolation, so config files stay commitable. Model precedence runs from a per-thread override file down through thread config, pattern, then global config.

Surface

Built-in commands

Slash commands, any channel

CommandEffect

Custom commands

Declared in config

A config entry gives a command its name, description, optional mode and skill list, plus a prompt appended after whatever the user typed — so the injected instruction is always the most recent one. Custom commands appear in the help listing and the dashboard popup.

CI gates

Green or it does not merge

Every push to main and every non-draft PR runs formatting, clippy with warnings denied across all targets, and the full test suite under coverage with a 60% floor.

Test discipline

Isolated and parallel-safe

Tests use temporary directories that clean themselves up, never mutate process environment, and never depend on network or fixed paths — so the default parallel run is stable.
